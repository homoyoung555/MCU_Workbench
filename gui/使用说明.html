Pattern → FB MAP 字段映射

在左侧选择 pattern 工作表，点击配置行的行号，再点“FB MAP 映射”。先选择该行中的已有字段，再从 FB MAP 等宽物理字段中改选目标，点击“应用到草稿”。可按字段名、寄存器或七位二进制地址搜索。

FB MAP 是字段名、地址和位段的依据；原值与动态标记保留，不自动截断或扩展。单字段行允许改寄存器地址；多字段行只允许同地址改选，同一行位段重叠会拒绝。此操作修改共享 Pattern，所有引用它的 FLOW 项都受影响。当前字段在 FB MAP 未匹配或名称不符时会显示状态，不能据此猜测自动改写全部配置。

改动进入原有草稿、一次撤销和另存链；“恢复”可用撤销退回，也可手动改选原字段。此处校验当前映射，工作簿其他问题不阻止打开修正；另存和生成仍需完整“检查当前改动”通过。当前仅支持已有字段重映射；新增和删除配置仍在表格中编辑。界面和整体性能优化另行安排。

TRIM 按用途选择 Pattern

在 FLOW 选中普通 TRIM，点击右侧关联区的“选择 Pattern 用途”。对“进入测试模式”和“写 DAC（搜索、调整及最终判定共用）”分别选择当前工作簿中的整份 Pattern。每次选择通过整本检查后，自动应用到当前行 Recipe 草稿；其他 CP 和其他 FLOW 项保持独立。

对话框显示当前 Pattern、绑定来源以及寄存器和字段摘要。候选按角色列出，动态字段等兼容性仍由编译检查；失败会显示原因，草稿不会被替换。必需用途不能解除。“恢复按 item 解析”移除该用途的显式选择，恢复既有解析规则，并不恢复该行全部导入内容。CTRL+Z 可撤销一次选择；暂存、另存工作簿及重开均保留已应用的选择。若 Recipe 编辑器还有未应用修改，请先应用或放弃再选择 Pattern。

选择写入当前行 Recipe 的 ENTER(PATTERN=...) 或 TRIM(PATTERN=...)，位置参数和等待参数保留。协议进入/退出、依赖项 DAC 和特殊流程仍按原有计划执行；本功能不修改 Pattern 内部字段。当前厂商编译验证仅覆盖 Chroma，未验证上机。

拖动调整执行顺序

按住行号旁的 ⠿ 上下拖动，绿色横线表示插入位置，松开即可移动。靠近表格上下边缘可滚动；Esc取消，选中把手后也可用Alt＋↑/↓微调。

FLOW按同一CP内连续同名、同类型测试项整体移动，全部sub和参数一起跟随。行号随新顺序更新，Ctrl＋Z可撤销；浏览器暂存和另存Excel都保留新顺序。搜索状态下请先清除搜索；含公式、合并或其他位置依赖的保护范围不能移动。调整顺序后需重新检查测试依赖。

Recipe页拖动模块左侧⠿，参数随模块移动。点击“应用到草稿”后写入该item的Recipe。默认灰字流程只有实际改动才变为显式Recipe，点击或原位放下不会写入。

TRIM 的存储映射来源

在 FLOW 选中普通 TRIM 测试项，打开“关联预览”，可同时查看 Pattern 和“ADDR_MAP 存储映射”。映射从上层已编译的 BUILDMAP/COMMIT 计划提取，显示 CP、DAC_FINAL 来源、存储页面、寄存器有效值内的位段及位宽；点击来源按钮可跳到 ADDR_MAP 字段或使用结果的 FLOW Recipe。

这里展示已识别的数据组装关系，不表示已经烧写；未解析到绑定时明确提示，不按测试项名称猜测，也不直接判定缺失。普通 TRIM 可点击“设置存储映射”，选择页、寄存器和字段后应用到草稿。应用时会检查目标、位宽、占用及编译结果；一次撤销可恢复原映射。

点击字段配置 TRIM / VERIFY 存储位置

打开“存储映射”，左侧选择 FLOW 的 TRIM / VERIFY 项，右侧按页和寄存器展开 ADDR MAP 的 description 字段。点击字段即建立映射，再次点击解除；每次操作可撤销。没有 description 的行使用 CP addr map 字段。

TRIM 保存 DAC_FINAL，VERIFY 保存测量结果。两类映射分开保存，同一逻辑项跨 CP 共用固定位置，可绑定多个位置，同名字段也能单独选择。VERIFY 需有可存储的结果格式，缺少格式时界面给出提示。

解除最后一个位置表示明确未绑定；“恢复导入映射”才会恢复 Excel 的旧推导规则。浏览器暂存、撤销/重做、另存草稿和另存检查结果均包含映射。映射随 GUI 保存的 xlsx 副本内嵌保存，不要求手填 ADDR_MAP 的 trim 名称。每次点击均经编译校验，位宽不足、字段占用、后续使用冲突会被拒绝。

外部 Excel 软件重新另存是否保留扩展尚未验证，请保留 GUI 保存的副本。导入另一份 Excel 目前仍是载入新工作簿，尚未实现版本合并与冲突裁决。Pattern 与 TRIM 的“进入、写 DAC、判定”等用途选择尚未实现。

检查通过后的另存与生成

“生成与导出”页显示已选目标、输出根目录和当前缺少的条件；可在本页检查配置、另存检查结果或另存未验证草稿。检查通过后选择目标，再预览或生成；另存Excel不是生成的前置步骤。较小窗口可滚动查看完整目标和准备信息，生成操作栏保留在底部。

本次打开工作台期间，最近另存路径会保留在准备区，标明是未验证草稿还是检查结果。保存后继续修改，会显示“后续改动尚未保存”；刷新或重开窗口后此路径记录不保留。生成结果汇总成功、失败和未提供目录的目标数，保留各目标具体错误、目录和文件查看入口。状态查询失败时使用原任务的“重试查询”；目标生成失败则先修正原因，再选择目标检查和生成。

检查、修正与复查

检查摘要始终显示实际范围：完整程序检查整本工作簿的所有CP和测试项，不受当前选格、搜索或生成目标筛选影响；独立资源检查显示所选资源与目标。

检查后显示错误、提醒数量及首个问题摘要。“首个问题”“上一项”“下一项”优先按错误、提醒顺序导航，自动打开工作表和隐藏列；没有单元格来源的问题在检查记录中查看。

改值后保留上次问题列表和当前选格，标记“待复查”，可继续查看原位置，但旧错误标记不再作为当前值的判断。行顺序或行结构改变后，旧位置导航暂停，需重新检查。“复查”执行当前范围检查；同一工作簿、范围、行结构下显示本次已解决的问题数。检查通过后提示另存或生成，独立资源通过仅适用于该资源。
