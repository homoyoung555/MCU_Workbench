首次使用

  1. 安装 Microsoft Edge WebView2 Evergreen Runtime（若系统尚无该运行时）。EXE 自带 Python。
  2. 从 input/workbook/ 选择需要的程序 Excel；也可以独立使用 SWD、SCAN、HEX。
  3. AI 助手打开独立窗口，在模型设置中输入自己的 API 并测试连接。旧电脑的加密密钥无法直接作为新电脑配置使用。
