1. 填写口径

必填：不能留空，也不能填写 /。
留空：由对应 Typed Kind 采用默认 Recipe。只有明确支持默认 Recipe 的类型才能留空。
/：当前测试项明确不使用该列。不要用 / 代替“留空采用默认 Recipe”。

2. KEIL / SWD 公共列

列要求说明
CP NO必填测试项所属 CP。
item必填测试项身份；部分深类型要求使用已注册名称。
type必填本文测试通常为 verify，最终以 Typed Kind 合同为准。
mode必填填写 swd 或 keil。
Hbin / Sbin必填硬件 Bin 与软件 Bin。
Vcc必填测试供电条件。
PE通常填 /仅明确需要 ERASE/PROGRAM 分段判定时填写。

4. KEIL 类型

4.1 通用固件执行

RecipesubstepMeas PinTargetUNITVcc
RUN_SEQUENCE-JUDGE必填必填判定管脚或电源轨数字状态或标量目标数字判定填 /；标量填 A/V 单位必填
  • 数字示例：Meas Pin PA13+PA11，Target HH；管脚数与状态字符数必须一致。
  • 若 step 含 F，必须填写对应 Force 事实：电源、时钟或管脚电压。
  • 需要下载固件时，在同 item 前放置连续的 mode=hex 行；HEX 行 Recipe 必须留空，step 填固件 Pattern 身份。

4.2 ADC KEIL

用途RecipesubFV / FIstepMeas / Target / UNIT

数字管脚判定RUN_SEQUENCE-JUDGEADC1 / ADC2与 sub 一致必填按数字判定填写，UNIT 为 /

4.3 PVD KEIL

RecipeFV / FIMeas PinstepLow / Target / High / UNIT
留空（默认 PVD_TEST）PVD两个不同管脚，以 + 分隔含动态 X，如 HL-222-15-X/

4.4 OPA / DAC KEIL

类型RecipeTargetFLOW step其他旧测量列
OPAOPA_TEST/含 X 分隔符，如 HL-222-X-FS/
DACDAC_TEST分辨率含 X 分隔符/

此处 X 是 FLOW step 的阶段分隔符，不是动态码值；实际 OPA/DAC 动作由各自 Sheet 的 step 定义。

4.5 VIH / VIL KEIL

  • item 为 DC_VIHVIL_Test，两个 sub 行连续且角色完整。
  • Recipe 留空，默认 VIH_VIL_TEST；mode 填 keil。
  • 每行 step 必须有效；Meas Pin 填 DC；两行 Vcc 保持一致。
